fm1-insert-coin

1980s arcade games as firmware for the M-Vave FM-1 synth: one firmware, a menu, these games. In the browser they run with the same C code as the firmware, compiled to WebAssembly.

  • SPACE INVADERS
  • BREAKOUT
  • GALAGA

Play them in the browser: the simulator runs the firmware, menu included.

Install the games on your FM-1: from the browser, with a USB cable.
