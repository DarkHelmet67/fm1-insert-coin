# Single prompt

The prompt that recreates this repository as it is today. It must be updated with every significant change.

---

Create the **fm1-insert-coin** monorepo: 1980s arcade games as firmware for the M-Vave FM-1 synthesizer (JieLi AC791N, no FPU, 240 × 240 RGB565 screen on SPI, 27 keys, 14 buttons, 7 encoders). License GPL-3.0-only. Everything in English: code, comments, documentation, web pages, pull requests (the project is shared with the international FM-1 community).

**Platform.** Copy [Dinghy](https://github.com/zvenson/dinghy) 0.4 (commit `22acb91`) into `platform/` without designburg's logo, `docs/screen.png` and `.github/`; note origin and changes in `platform/UPSTREAM.md`. Do not modify `platform/`.

**Structure.** `libs/` (shared code, pure C), `games/<game>/` with `firmware.json` (`identity` FM-1_9N, `screen_name`, `screen_colour` RGB565 in hexadecimal), `src/main.c` (the only file that includes `platform.c` and defines `app_main()` and `app_audio()`), `src/config.h` (the values that are choices), `scripts/*.txt` (host mode scripts). `tools/build.py GAME`: an adaptation of `platform/tools/build.py` that compiles `main.c` plus every other `.c` of the game and of `libs/` as a separate object (excluding `*_test.c`), with Dinghy's checks extended to our files; FM-1 only. `tools/ppm_to_png.py`: host mode screenshots as 480 × 480 PNG.

**Rules** (in `CLAUDE.md`): code for humans; small files; pure logic with state passed as `const T *` and the new state returned; integers only; Doxygen comments everywhere; `-std=c99 -Wall -Wextra -Werror`; clang-format (LLVM, indent 4, 100 columns, Linux braces); uncertain values in `config.h`; tests `module_test.c` next to the module with the `libs/test/check.h` harness (`CHECK`, `CHECK_EQ`, `RUN`, `check_report`).

**Makefile.** `make test` (builds and runs every `*_test.c` with all the `.c` files of `libs/` and, in a game, the other `.c` files of its folder except `main.c`), `make host GAME=… [SCRIPT=…]` (the game with `-DDINGHY_HOST`, then the screenshots as PNG), `make format`, `make format-check`.

**CI** (`.github/workflows/ci.yml`, on every push and PR): job `host` (format-check, tests, every game in host mode, screenshots as an artifact) and job `firmware` (JieLi toolchain from pkgman.jieliapp.com, AC79 SDK `AC79NN_SDK_V1.2.1_2023-12-13` from gitee.com, `tools/build.py` for every game, `.fwsc` as an artifact).

**libs/input.** `fm1_keys.h`: the keys by position and the labels of the black keys (OP1 = 1, OP2 = 3, OP3 = 5, OP4 = 8, OP5 = 10, OP6 = 13, PIT = 15, GLO = 17, MONO = 20, POLY = 22, from fm1_open's `edit_keys` table). `keymap.h/.c`: `KeyMap {left, right, fire}` as masks of `fm1_in.notes`; `keymap_actions()` returns the bits `ACTION_LEFT`, `ACTION_RIGHT`, `ACTION_FIRE`, with left and right together cancelling out; `keymap_keys()` all the keys used.

**libs/screen and libs/clock.** `framebuffer.h/.c`: `Framebuffer` (at most 240 × 288, one byte per pixel with a colour index out of 16, one "changed" bit per row), `fb_init`, `fb_get`, `fb_set` (marks the row only if the pixel changes), `fb_fill_rect`, `fb_row_dirty`, `fb_mark_all_dirty`, `fb_clear_dirty`, macro `RGB565`. `screen_map.h/.c`: `ScreenMap` (for each of the display's 240 rows the game row or `SCREEN_NO_ROW`, columns centred 1:1), `screen_map_centered(w, h)`, `screen_map_rows(w, RowRange[], n)` (ranges of rows stacked and centred). `screen_push.h/.c`: `screen_next_band()` (next range of changed rows, at most N) and `screen_render_row()` (one row coloured with the palette). `screen_fm1.h` (included by `main.c` after `platform.c`): two 240 × 32 buffers in the pool, `screen_palette()` (bytes swapped for the display), `screen_clear()`, `screen_push_band()` (one band of changed rows per call, from where the last ended; none left: clears the changes and returns 0). `frame_clock.h/.c`: `frame_clock_frames(ms)` = ms × 60 / 1000 without overflow or 64-bit division. On macOS the `Makefile` adds `-D'section(x)=section("__DATA,__pool")'` to the host build.

**Traces (step 3).** `tools/traces/record-space-invaders.mjs INSERT_COIN_DIR [OUT_DIR | --dump NAME FRAME]`: loads insert-coin's `games/space-invaders/src/*.ts` with `createServer` + `ssrLoadModule` of insert-coin's Vite, plays three scripts (`idle`: coin at frame 60 and nothing else, 6000 frames; `restless`: coin, then right/left every 90 frames and fire every 20, 6000; `aiming`: coin, then runs from a bomb with y > 120 within 18 pixels of the cannon's centre, otherwise moves under the nearest invader and fires when aligned, 20000) and writes `games/space-invaders/traces/<name>.trace` in the format of `tools/traces/FORMAT.md` (line `frame controls screen hash s= l= r= n=`, 32-bit FNV-1a hash of the canonical state string). `make traces INSERT_COIN=…`. `libs/trace/text.h/.c` (4096-byte `Text`, `text_add`, `text_add_char`, `text_add_int`, `text_add_hex`, `text_cstr`, `text_fnv1a`) and `trace_line.h/.c` (`trace_parse_line`).

**Space Invaders, step 1.** Identity `FM-1_95`, update screen "SPACE INVADERS" in green `0x07E0`. Keys: OP1-OP3 left, OP4-OP5 fire, OP6-PIT-GLO right. `main.c`: title "SPACE / INVADERS" in white FONT_L, "FM-1 EDITION" in green, legend "OP1-3  OP4-5  OP6-GLO" at the bottom; the game keys lit dimly and fully when pressed; a line shows the actions (`<`, `FIRE`, `>`). Audio silent.

**Space Invaders, step 2.** `config.h` adds `GAME_WIDTH` 224, `GAME_HEIGHT` 256, `SHOWN_ROWS` {8-239, 243-250}, the colour indexes (background, text, cannon, UFO, shots, three alien rows) and the palette of colors.config.ts. `main.c` shows a test card (borders, green line at row 239, three reserve cannons at row 243, five coloured bars) and a 13 × 8 block at row 216 that the keys move one pixel per frame (white with fire), with `frame_clock`'s 60 Hz loop (at most 4 frames to catch up) and `screen_push()` at every turn (replaced by the game in step 5).

**libs/sprite.** `sprite.h/.c`: `Sprite {width, height, rows}` with the rows as strings (`X` lit), `SPRITE_DEFINE(name, width, rows...)`, `sprite_lit`, `sprite_is_well_formed`. `bitmap.h/.c`: `Bitmap` (at most 32 × 16, one 32-bit word per row, bit 31 on the left), `Placed {bitmap, x, y}`, `bitmap_from_sprite`, `bitmap_lit`, `bitmap_count`, `placed_overlap` (common rectangle, then pixel by pixel), `bitmap_erase(target, brush)`.

**Space Invaders, step 4 (logic).** In `games/space-invaders/src/`, one module for each insert-coin logic file, with the same name: `sprites` (all the drawings of sprites.ts, `alien_sprite(kind, frame)`, `bomb_sprite(kind, steps)`, `cannon_explosion_sprite`), `aliens` (8-byte `Alien`, `formation_alien(index, round)` in marching order, `start_bottom_y`, `alien_width`, `alien_points`), `fleet` (`Fleet` with 55 invaders, `fleet_create/step/remove/bottom/touches_edge`), `cannon` (`cannon_move`, `cannon_center`, `Shot`, `shot_fire`, `shot_move`), `bombs` (`Bombs` with at most 3 bombs in launch order, `bombs_step` with `BombContext` {fleet before the step, cannon centre, score}, `bombs_remove`, `reload_steps`, `bomb_speed`, `lowest_in_column`, `column_above`), `ufo` (`ufo_step`, `ufo_score`, `ufo_shot_down`), `shields` (`shields_create/hit/damage`), `effects` (at most 24, `floor_div` to centre explosions like `Math.floor`), `collisions` (the nine rules of collisions.ts), `playing` (`playing_initial`, `playing_step` with the rules in an array of function pointers plus `next_round_if_cleared`, `playing_is_over`), `game` (`GameState`, `game_initial(hi)`, `game_step`), `controls.h`. No debug mode. `trace_state.c` writes the string of FORMAT.md; `parity_test.c` replays the three traces and compares the hashes at every frame (from the repository root). Unit tests translated from insert-coin's for every module. Guide `docs/04-logic.md`.

**Drawing libs.** `screen/framebuffer` adds `fb_present(front, back)` (copies into `front` only the rows that differ and marks them changed). `screen/draw.h/.c`: `fb_draw_sprite`, `fb_draw_bitmap`, `fb_clear`. `font/font.h/.c`: `PixelFont {glyph_width, glyph_height, spacing, chars, glyphs}`, `font_glyph` (lower case as upper case), `font_text_width`, `fb_draw_text`, `fb_draw_text_centered`; `font/arcade_font.c`: insert-coin's 5 × 7 font (arcade-font.ts), spacing 3. `storage/hi_score_fm1.h`: `HiScoreRecord {version, hi_score}`, `hi_score_load()`, `hi_score_save()` with Dinghy's `settings_load/save` (replaced by the launcher's records).

**Space Invaders, step 5 (graphics and controls).** `config.h` declares and `config.c` defines `CONTROLS`, `SHOWN_ROWS`, `COLORS` and `MONO_COLORS` (all white); `COIN_BUTTON` 12 (PLAY), `COLOR_BUTTON` 2 (FX); attract texts and rows "PRESS PLAY" (200), "<OP1-3 FIRE OP4-5 OP6-GLO>" (214), "<FX> MONO-COLOR" (226). `input.h/.c`: `input_controls(map, notes, previous_notes, button_presses, coin_button)`, movement from the keys held, fire and coin as presses. `render.h/.c`: `render_game(fb, game)` from scratch like render*.ts (header with SCORE<1> and HI-SCORE, shields, invaders coloured by row, saucer, bombs, effects, shot, cannon or explosion alternating every 5 frames, green line and reserve cannons; attract with title, score table animated every 30 frames and "PRESS PLAY" lit for 30 frames out of 60; "GAME OVER" in red at row 56), `format_score` with 4 digits. `main.c`: `STORE_MAGIC` 0x494E5644 before `platform.c`; two framebuffers in the pool (`front`, `back`); at every turn the frames due with `input_controls` + `game_step` (a press counts in the first only), saving the high score when not playing and the high score went up, `render_game(back)`, `fb_present`, LEDs (game keys dim, full when pressed, PLAY blinking when a game can start, FX dim), `screen_push`; FX changes palette and marks every row. A host script that presses PLAY, moves, fires and switches to black and white. Guide `docs/05-graphics-and-controls.md`.

**libs/audio.** `sound.h`: `Sound {kind (SOUND_TONE/NOISE), wave (WAVE_SQUARE/TRIANGLE/SAWTOOTH), sweep, fade (CURVE_EXPONENTIAL = 0 default, CURVE_LINEAR), from_hz, to_hz, cutoff_hz, delay_ms, duration_ms, hold_ms, volume in thousandths}`, `SoundEffect {layers, count}`, `SOUND_EFFECT(array)`. `pow2.h/.c`: `log2_q16(x)` and `scale_pow2(value < 2^17, exponent_q16)` with interpolated 65-entry tables. `voice.h/.c`: `Voice`, `voice_silent`, `voice_start`, `voice_is_free`, `voice_render(voice, mix, n)`; 44,100 Hz, 32-bit phase (97,392 per hertz), square at 27,525 (−1.5 dB like the web's band-limited waves), sawtooth, triangle, xorshift noise; pitch and volume recomputed every 32 samples, exponential sweeps and fades as straight lines in octaves (fade down to 0.0001), linear ones as straight lines; two one-pole low-passes at 1.5 × the cutoff. `mixer.h/.c`: 16 voices, `mixer_silent/play/stop/render/is_playing` (when full: replaces the oldest). `audio_fm1.h`: a 16-effect queue between loop and interrupt (`audio_play`, `audio_render` in `app_audio`, mono on both channels, `audio_is_playing`).

**Space Invaders, step 6 (sounds).** `sounds.h/.c`: `SoundName` (coin, shot, alienHit, ufo, ufoHit, cannonHit, extraLife, newRecord, march0-3), `SOUND_EFFECTS` with the numbers of sound-bank.ts, `sounds_for(before, after)` like sounds.ts (coin on entering a game; march note `beat % 4` at every change of `beat`; laser, invader hit, saucer hit, cannon explosion, extra cannon, saucer chirp every 10 frames of flight; fanfare once if there was a high score and it is beaten). `effect_frames(kind)` in effects. `main.c`: `play_sounds(sounds_for(...))` at every frame, `audio_render` in `app_audio`, high score saved only if `!audio_is_playing()`. `make sounds INSERT_COIN=…`: `tools/sounds/render_sounds.c` (C → `build/sounds/c`), `tools/sounds/render-web-sounds.mjs` (data from sound-bank.ts via Vite, sound.ts and synth.ts with types stripped by insert-coin's `typescript`, `OfflineAudioContext` in Chromium with Playwright → `build/sounds/web`), `tools/sounds/compare.py` (correlation of the 10 ms RMS envelope, volume in dB, pitch from 50 ms zero crossings). Exception in CLAUDE.md for the synthesizer voices. Guide `docs/06-sounds.md`.

**Space Invaders, step 7 (simulator).** `app.h/.c`: `App {game, mono, sounds}`, `app_initial(hi)`, `app_step(app, notes, note_presses, button_presses)` (input_controls, game_step, sounds_for, FX toggles `mono`), `app_record_to_save(app, saved)`; `input_controls` now receives the key presses (`note_presses`) instead of the previous frame's keys. `main.c` accumulates `note_presses` (`fm1_input_note_edges()` plus the edges of `fm1_in.notes`) and `button_presses` until the frame that uses them, then `app_step`. `sim/sim.h` (`SIM_EXPORT`), `sim/libc.c` (memcpy, memmove, memset, memcmp), `sim/shell.html`, `sim/style.css`, `sim/sim.js` (27-key keyboard with OP1-POLY labels, FX 2 and PLAY 12 buttons with LEDs, multiple pointers, computer keys: arrows/A/D, space/W, Enter/C/5, V; `requestAnimationFrame` at 60 Hz with 4 to catch up; `ScriptProcessor` at 44.1 kHz started at the first touch; high score in `localStorage`). `games/space-invaders/sim/sim.c` exports `sim_init`, `sim_frame`, `sim_screen` (render_game, then `screen_render_row` at `dest_x` with the background on the sides, as RGBA), `sim_audio`, `sim_game_keys`, `sim_coin_button`, `sim_color_button`, `sim_waiting`, `sim_record_to_save`. `make sim GAME=…`: clang `--target=wasm32 -nostdlib -ffreestanding -Wl,--no-entry -Wl,-z,stack-size=131072`, then `tools/sim/bundle.py` (a single page with the wasm as base64 in `build/site/<game>/index.html` and the index `build/site/index.html`). `tools/sim/smoke.mjs` (Node, no browser) and `tools/sim/test.mjs` (Playwright). CI: job `simulator` (clang, lld, `make sim` and smoke for every game, `simulator` artifact). Guide `docs/07-simulator.md`.

**Web installer (after the plan, Luca's request).** `installer/vendor/fm1ota.js` and `fm1pkg.js` copied from Skiff (commit `b03d98a`, Leo Kuroshita, GPL-3.0) with a single change noted in `installer/UPSTREAM.md`: `Updater.find()` pairs the output that has the input's name or contains it (Windows: "MIDIOUT2 (Felucca)"). `installer/package.js`: `checkedImage(bytes, entry)` (size, SHA-256 and identity as in `games.json`, then `logicalImage`), `loadImage(entry)` (`fetch` with `no-cache`), `isOurLoader(id)` (`ota-FM-1_9NN`). `installer/texts.js`: texts in English and Italian, always English at the start, an Italiano/English button. `installer/installer.js`: list of games from `games.json` with links to the simulator and the `.fwsc`, Install (`requestMIDIAccess({sysex: true})`, `find`, FM-1 model, another firmware's loader refused, `resume` if it is in our loader, `install` otherwise), progress bar (5 % the check, the rest the write), technical details. `tools/installer/bundle.py OUT_DIR FWSC...`: checks every package with `load_package` of `platform/tools/fm1_install.py`, copies it to `OUT_DIR/firmware/<game>.fwsc`, copies the page to `OUT_DIR/installer/` with `games.json` and rewrites the site index (which skips folders that are not games and links the installer when present). `tools/installer/fake_fm1.mjs` (a fake FM-1 behind a fake `MIDIAccess`, like `FakeFM1` in `install_test.py`), `fake_package.py`, `test.mjs` (12 checks, `make installer-test`, also in CI's `host` job), `page-test.mjs` (Playwright). `make installer [FWSC=…]`. **PR previews.** `.github/actions/publish-pages` (from insert-coin): the published site lives on the `gh-pages` branch; it puts a site at the root (`target: .`, keeping the `pr-*` folders) or in `pr-<number>` (empty: removes it), commits and leaves the tree in `_pages`. `ci.yml` on `main`: job `publish` (downloads `site`, `publish-pages` with `target: .`, `upload-pages-artifact` of `_pages`) and `pages` (`deploy-pages`), concurrency group `pages`. `.github/workflows/preview.yml`: on `ci`'s `workflow_run` (event `pull_request`, green, same repository, PR open, not a draft, `head.sha` equal to the commit built) downloads the run's `site` artifact and publishes it in `pr-<number>`; on `pull_request_target` `closed` removes the folder if it exists; then `deploy-pages` and a comment on the PR marked `<!-- pr-preview -->` (created or updated). **Launcher (one firmware, a menu of games; supersedes the per-game `main.c`, `sim/sim.c`, `firmware.json` and `hi_score_fm1.h`).** `libs/cartridge/cartridge.h`: `Panel {notes, note_presses, buttons, button_presses, turns[7]}` and `Cartridge {name, record_tag, state_size (≤ CARTRIDGE_STATE_MAX 16384), width, height, screen_map(), start(state, hi), step(state, panel), render(state, fb), colors(state), sounds(state), sound_effects, voices(state), wsg_prom, hi_score(state), playing(state), keys(), buttons}`; `libs/cartridge/private.h`: `GAME_PRIVATE`/`GAME_EXTERN`, `static` under `GAME_AMALGAMATION`.
